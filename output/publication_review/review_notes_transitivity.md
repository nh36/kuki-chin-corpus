# Why there is no dictionary slice

There is no dictionary slice because this is a grammar-facing and argument-structure-oriented packet rather than a lexical-headword packet.

The current packet should not create dictionary entries for `sih`, `suak`, `hawl`, `en`, `mu`, `muh`, or other verb strings, because the packet is establishing a narrow argument-structure contrast rather than a lexical inventory.

# What does not yet work
