# Why there is no dictionary slice

There is no dictionary slice because this is a grammar-facing and constructional packet rather than a lexical-headword packet.

The current packet should not create dictionary entries for `mahmah`, `taktak`, `peuhpeuh`, or other reduplicated strings, because the packet is establishing a narrow constructional claim rather than a lexical inventory.

# What does not yet work
