# Partially lifted domains

The main second-pass gaps are now clearer precisely because so many first packets exist.

- VP structure still has obvious work beyond `bawlzoding`, especially broader suffix-slot ordering, cross-domain stacking, and subordination or sentence-final overlap.
- derivation / valency still has obvious work beyond `-sak`, especially `-pih`, productive versus lexicalized `ki-`, derivation-heavy stacking, and transitivity adjacency.
- clause linkage still has obvious work beyond `ciangin`, especially switch reference and relative clauses.
- nominalization still has obvious work beyond `-na`, especially `-pa`, `-mi`, nominalized relatives, and nominalization-plus-case.
- NP structure / possession still has obvious work beyond basic NP order, especially nominal-host possession, possessor chains, and broader possessor syntax.
- noun domain still has obvious work beyond simple noun stems, especially transparent compounds and proper nouns.
- reduplication still has obvious work beyond intensifying full reduplication, especially distributive, syntactic, verbal, aspectual, and lexicalized-looking rows.
- prefix/agreement still has obvious work beyond `kanei` / `kainn`, especially hong-/kong- object-prefix or inverse-like rows and `ki-` boundary material.

These are real second-pass opportunities, but they are not the same as genuinely unlifted domains. Most of them should wait for human review on the current narrow packet before they are widened.

# Still unpacketized or blocked domains

The checkpoint leaves three main kinds of gap.

First, phonology/tone remains unpacketized and still looks blocked or theory-heavy. `docs/grammar/GRAMMAR_SOURCE_INVENTORY.md` shows real phonology and tone sources, and `docs/SKELETON_GRAMMAR.md` still expects a phonology chapter, but `output/publication_review/whole_grammar_coverage_audit.md` still treats phonology and tone as blocked because tone in `-a` and related analyzer-gap issues remain unresolved.

Second, transitivity remains report-backed but unpacketized. `docs/grammar/reports/05-verb-12-transitivity.md` is present in the inventory, and the audit still treats transitivity as current evidence with no packet yet.

Third, some broader architecture domains remain only partly surfaced rather than packetized on their own: verb paradigms are still report-backed but unpacketized, discourse beyond the current sentence-final slice is only partially lifted, and analyzer-gap topics remain cross-cutting blockers rather than finished chapter material.

This means the remaining problem is no longer “find any missing domain at all.” It is now “separate genuinely unlifted report-backed work from narrow packets that should stay stable.”
